# Acidophilic

## Dataset

The dataset used in this study was derived from the benchmark dataset constructed in the original acidophilic protein prediction study. It consists of acidophilic and non-acidophilic protein sequences collected from the National Center for Biotechnology Information (NCBI) , with a pre-defined development set and an independent test set. The resulting development set contained 4,594 sequences in total, including 3,271 positive and 1,323 negative samples, while the independent test set contained 1,149 sequences, including 818 positive and 331 negative samples.
